# Changes

Upstreams merged into oneVR, and oneVR's own changes to them.

## Upstreams

Merged as git subtrees without `--squash`, which keeps upstream history and authors. `.github/scripts/upstream-watch.py` reports unmerged upstream commits every day.

| Name | Repo | Branch | Prefix | Local edits |
|------|------|--------|--------|-------------|
| xrizer | 360900/xrizer-edge | main | xrizer | no |
| wivrn | WiVRn/WiVRn | master | wivrn | yes |
| wayvr | wayvr-org/wayvr | main | wayvr | yes |

`xrizer/` takes no local edits. Changes go to xrizer-edge first, which tracks Supreeeme/xrizer.

Merging an upstream:

```sh
git fetch --no-tags https://github.com/WiVRn/WiVRn.git master
git subtree merge --prefix=wivrn <sha> -m "wivrn: merge WiVRn/WiVRn master at <sha>"
cargo xtask rebrand
```

`cargo xtask rebrand` re-applies the oneVR name and logo. On a merge conflict in a rebranded line, take upstream's side and run it again; `cargo xtask rebrand --check` (also run by CI) reports rules that no longer match. When upstream changed an image oneVR replaces, rebrand fails and names the oneVR file to compare it with; update that file if needed, then run `cargo xtask rebrand --accept-images`.

oneVR's Monado patches are `wivrn/patches/monado/onevr-NNNN-*.patch`, which sort after upstream's `NNNN-*.patch` and apply last.
